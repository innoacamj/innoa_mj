## 2. 사용 도구 및 선택 근거

### 2-1. 메인 도구

| 구분 | 도구 | 용도 | 선택 근거 (품질·제어·속도·비용) |
|---|---|---|---|
| 이미지 생성 (T2I) | Midjourney | 씬별 키비주얼 | 시네마틱 조명·색감 품질 우수, `--sref`로 스타일 고정 가능, 1회 4장 생성으로 시도 대비 효율 높음 |
| 비디오 생성 (I2V) | Runway | 키비주얼 → 5~10초 모션 컷 | 시작 프레임 고정으로 구도·색감 유지, 카메라 모션 지시(패닝·줌인·슬로모션) 제어 용이 |
| 오디오 생성 | Suno | 앰비언트·응원가풍 BGM·스팅어 | 장르·분위기 텍스트 지시로 오리지널 곡 생성, 기존 응원가 저작권 문제 회피 |
| 편집·통합 | CapCut | 컷 편집, 타이포 모션, 색보정, 자막, 오디오 믹싱 | 무료 범위에서 텍스트 애니메이션·LUT·키프레임 지원, 학습 비용 낮음 |

**우선순위:** ① 화면 품질(Midjourney) → ② 모션 제어(Runway) → ③ 비용 효율(Suno·CapCut)
비용이 가장 큰 단계는 Runway(초 단위 크레딧 차감)이므로, 키비주얼을 Midjourney에서 충분히 확정한 후 Runway에 투입하여 재생성 횟수를 최소화한다.

### 2-2. T2I · I2V 방식 비교 및 선택 기준

| 구분 | T2I (Text-to-Image) | I2V (Image-to-Video) | T2V (Text-to-Video) |
|---|---|---|---|
| 입력 | 텍스트 프롬프트 | 이미지 + 모션 프롬프트 | 텍스트 프롬프트 |
| 장점 | 빠르고 저렴, 여러 안 비교 용이 | 첫 프레임 고정 → 구도·색감 일관성 높음 | 이미지 단계 생략으로 빠름 |
| 단점 | 정지 이미지만 생성 | 크레딧 소모 큼, 큰 움직임 시 형태 왜곡 | 씬 간 스타일·색감 일관성 낮음 |
| 본 프로젝트 적용 | 전 씬 키비주얼 (씬1~5) | 전 씬 모션 컷 (씬1~5) | 미사용 |

**선택 기준:** 씬 간 블루 톤 통일이 핵심 요구사항이므로 "T2I로 구도·색감 확정 → I2V로 모션 부여" 방식을 채택. 씬6은 생성 없이 CapCut 그래픽으로 직접 제작.

## 4. 기술 표준 및 통합 규칙

### 4-1. 출력·생성 파라미터 표준

| 항목 | 표준 |
|---|---|
| 최종 출력 | 1920×1080, 16:9, 30fps, H.264 |
| Midjourney | `--ar 16:9 --style raw --sref ⟨씬1 채택 키비주얼 URL⟩` (씬2~5 공통 적용) |
| Runway | 16:9 생성, 컷당 5초 또는 10초 생성 후 편집에서 길이 조정 |
| Suno | 씬별 단일 곡이 아닌 '도입 → 긴장 → 절정 → 여운' 흐름을 2~3곡으로 나누어 생성 |
| 기준 색감 | 딥 네이비~일렉트릭 블루 계열, 하이라이트만 화이트 (붉은 계열 최소화) |
| 오디오 레벨 | 최종 믹스 −14 LUFS 기준, 내레이션 구간 BGM −6dB 덕킹 |

### 4-2. 스타일 일관성 제어

| 단계 | 방법 |
|---|---|
| 레퍼런스 고정 | 씬1 채택 키비주얼을 스타일 레퍼런스(`--sref`)로 씬2~5에 동일 적용 |
| 프롬프트 고정 | 전 씬 공통 스타일 문구(5-1 참고)를 프롬프트 끝에 동일하게 부착 |
| 후처리 | CapCut에서 동일 색보정 프리셋(블루 LUT)을 전 컷에 일괄 적용, 씬별로 노출만 미세 조정 |

### 4-3. 통합 시 불일치 보정 체크리스트

- [ ] **해상도:** Runway 출력물을 1920×1080 타임라인에 맞춰 리샘플링 (업스케일 필요 시 CapCut 화질 향상 기능 사용)
- [ ] **비율:** 16:9 외 컷은 크롭(중앙 기준) 처리, 레터박스 미사용
- [ ] **프레임레이트:** 전 컷 30fps로 통일, 슬로모션 컷(씬3-3)은 속도 조정 후 프레임 보간 적용
- [ ] **색감:** 블루 LUT 일괄 적용 → 컷 간 이어보기로 밝기 편차 확인
- [ ] **오디오:** 곡 전환 지점 0.5초 크로스페이드, 전체 라우드니스 측정
